# TurnIA Web Comercial

Sitio comercial independiente de la aplicación TurnIA.

## Reglas

- No contiene secretos ni tokens.
- No modifica la app `manriquedario-eng/turnIA-web`.
- No modifica Supabase, Mercado Pago, WhatsApp, ARCA, MisRx ni Digilogix.
- No cambia DNS ni dominios.
- Los links de alta/ingreso se configuran en `assets/js/config.js`.
- El sitio puede publicarse como hosting estático.

## Estado

Base reconstruida desde el diseño comercial aprobado y el resumen de implementación de septiembre de 2026.

Arquitectura objetivo:
- `www.turniahealth.com.ar` → web comercial.
- `app.turniahealth.com.ar` → aplicación TurnIA.

Antes de publicar en el dominio final se debe validar la web en Preview.
